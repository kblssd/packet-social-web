A social network you reach with a terminal.

There is no app and no website to scroll. You connect from your own terminal, and every post you read, send or like crosses the same network you are trying to learn. Built for people learning networking.

ssh -p 2222 packet.social

Paste it into Terminal (Mac or Linux) or PowerShell (Windows). No install, no password. Your SSH key is your account. No key yet? Run ssh-keygen -t ed25519 once and press Enter at each question. Just want a look first? Use ssh -p 2222 guest@packet.social, no key needed.

how it works

Open a terminalAny terminal that has SSH. Mac, Linux and Windows 10 or later all do.
Run the commandYour computer makes a connection and proves who it is with a key. Nothing to sign up for.
Pick a handleThen read the feed, post, like, and work through the daily challenge.

what you will learn

L7 applicationmethods, headers, status codes, signed requests
L6 presentationTLS, base64, hex, bytes versus characters
L5 sessionkeeping a connection open
L4 transportTCP for posts, UDP for likes
L3 networkaddresses, subnets, routes
L2 data linkMAC addresses, your local network
L1 physicalyour cable or radio, not our problem

hard mode

The same network is open to raw tools. Use curl to post with a signed request and netcat to send a like as one UDP packet. Doing it by hand earns a badge. The full guide is in the README.

curl https://packet.social/status curl https://packet.social/feed
